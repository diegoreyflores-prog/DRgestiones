# DR Gestiones - Sitio web

Sitio web corporativo preparado para GitHub Pages.

## Publicación rápida

1. Sube todos los archivos y carpetas de este proyecto al repositorio `DRgestiones`.
2. En GitHub entra a **Settings → Pages**.
3. En **Build and deployment**, selecciona:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
4. Presiona **Save**.
5. La dirección será:
   `https://diegoreyflores-prog.github.io/DRgestiones/`
