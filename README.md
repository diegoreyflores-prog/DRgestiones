# DR Gestiones - Sitio web v2.0

Versión completa para GitHub Pages.

## Cómo actualizar

1. Descomprime el ZIP.
2. En GitHub entra al repositorio `DRgestiones`.
3. Usa **Add file → Upload files**.
4. Sube todos los archivos y carpetas de esta versión.
5. Confirma el reemplazo y presiona **Commit changes**.

La página seguirá publicada en:

https://diegoreyflores-prog.github.io/DRgestiones/
